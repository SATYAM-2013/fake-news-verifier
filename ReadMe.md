## ⚙️ How It Works

1. Input news text
2. Preprocessing:

   * Lowercasing
   * Removing punctuation
   * Removing stopwords
   * Stemming/Lemmatization
3. Convert text → TF-IDF vectors
4. Pass to trained ML model
5. Output prediction (Fake / Real)
